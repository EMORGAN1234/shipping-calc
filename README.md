# Shipping Dimensions Calculator

Calculates shipping dimensions (OD, skid footprint, total stack height) for aluminum coil, sheet, and plate.

## Stack

- Vite + React 18
- Tailwind CSS v3
- lucide-react icons
- Vercel Analytics

## Local Dev

```bash
npm install
npm run dev
```

## Deploy

Push to `main` — Vercel auto-deploys.
